# Car Financing

Aplicação desktop em Java 21 com Swing.

## Requisitos

- JDK 21
- Maven 3.8+

## Comandos

```bash
mvn compile exec:java   # executa a aplicação
mvn test                # roda os testes
mvn package             # gera target/car-financing-1.0.0-SNAPSHOT.jar
java -jar target/car-financing-1.0.0-SNAPSHOT.jar
```
